# v1은 계정 없는 익명 투표, 쿠키 기반의 약한 중복 방지, 운영자 공유 비밀번호를 사용한다

이 앱은 동아리의 실제 의사결정에 쓰이지만, v1에서는 투표자 로그인을 구현하지 않는다. 투표는 완전 익명이며, "이 투표에 참여함"은 투표자 브라우저의 쿠키로만 기억한다. 이 쿠키로 결과 열람(투표한 사람만)과 같은 브라우저의 재투표 차단을 함께 처리한다. 다른 브라우저나 시크릿 창으로는 우회할 수 있으므로, 이것은 신뢰할 수 있는 중복 방지가 아니라 어색함을 줄이는 수준의 장치다. 운영자도 개인 계정 대신 모든 운영자가 공유하는 단일 비밀번호로 구분 없이 인증한다. "질문을 올리면 사람들이 선택지를 고르고 결과를 본다"는 원래 요청 범위를 단순하게 지키기 위해 신뢰성보다 단순함을 택한 트레이드오프이며, 투표자 신원(로그인, 확실한 중복 방지)과 운영자별 계정은 이후 버전에서 추가할 계획이다.
