# 08: 투표 마감 시각 (최대 7일)

**What to build:** 운영자는 투표를 만들 때 마감 시각을 반드시 정한다(지금 이후 ~ 최대 7일 뒤, 기본 24시간 뒤). 마감 시각이 지나면 투표는 마감됨이 되어 더 이상 투표할 수 없고, 결과는 누구나 볼 수 있다. 첫 화면과 운영자 목록, 투표·결과 화면에 마감 시각 또는 "마감됨"이 한국 시간으로 보인다. 기존 투표는 만든 시각 + 7일을 마감 시각으로 갖는다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 마이그레이션 SQL이 저장소에 있고, 사람이 Neon SQL Editor에서 실행한다(기존 투표는 created_at + 7일, 컬럼은 not null, 기본값 now() + 7일).
- [ ] 투표 만들기 화면에 마감 시각 입력칸이 있고 기본값이 24시간 뒤다. 최소·최대값이 지금 ~ 7일 뒤로 걸려 있다.
- [ ] 마감 시각이 없거나, 지난 시각이거나, 7일을 넘으면 화면과 API 모두 거부하고 이유를 보여준다.
- [ ] 마감 여부는 DB 시각으로 판단한다.
- [ ] 마감된 투표의 투표 화면은 결과 화면으로 보낸다. 마감된 투표에 제출해도 표가 기록되지 않고 결과 화면으로 간다(득표 증가 SQL 안에서 마감 여부를 함께 확인).
- [ ] 마감된 투표의 결과는 투표하지 않은 사람도 화면과 API로 볼 수 있다. 결과 열람 규칙은 화면과 API가 같은 함수 하나를 쓴다.
- [ ] 첫 화면·운영자 목록에 "마감: 10월 3일 18:00" 또는 "마감됨 · 10월 1일 14:32"가 보인다. 마감된 투표도 목록에 남는다.
- [ ] 투표·결과 화면에도 마감 시각 또는 "마감됨"이 보이고, 결과 화면은 5초 갱신 때 마감 상태도 갱신된다.
- [ ] Playwright 테스트: 기본값 확인, 각 거부 사례, 몇 초 뒤 마감되는 투표로 자동 마감 후 투표 차단·결과 공개·목록 표시 확인.
