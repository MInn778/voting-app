# 06: 운영자가 투표 삭제

**What to build:** 로그인한 운영자가 운영자 목록(`/operator`)에서 투표를 삭제한다. "정말 삭제할까요?" 확인을 한 번 거친 뒤, 투표와 그 선택지·받은 표가 모두 영구 삭제되고 첫 화면과 운영자 목록에서 즉시 사라진다. 투표는 수정할 수 없으므로 고치려면 삭제 후 새로 만든다.

**Blocked by:** 03 (운영자가 투표 만들기 + 첫 화면 목록)

**Status:** done

- [x] 삭제 버튼을 누르면 확인 단계가 나오고, 취소하면 아무것도 지워지지 않는다.
- [x] 확인하면 투표가 삭제되고 선택지와 득표도 cascade로 함께 사라진다.
- [x] 삭제 직후 첫 화면과 운영자 목록에서 그 투표가 보이지 않는다(캐시에 남지 않음).
- [x] 삭제된 투표의 투표·결과 주소로 들어가면 "투표를 찾을 수 없습니다"가 보인다.
- [x] 로그인하지 않은 사람이 `DELETE /api/polls/[id]`를 직접 호출하면 거부된다.
- [x] Playwright 테스트: 취소 시 유지, 확인 시 두 목록에서 사라짐, 삭제된 투표 주소 안내, 비로그인 API 거부. 득표가 있는 투표도 삭제되는지 확인한다(표는 04가 없어도 DB에 직접 넣어 검증 가능).
