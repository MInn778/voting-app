# 10: 결과를 가로 막대 그래프로 표시

**What to build:** 결과 화면에서 선택지마다 득표 비율만큼 채워진 가로 막대가 보인다. 숫자("3표 · 60%"), "✓ 내 선택" 강조(초록색 막대), 5초 자동 갱신은 그대로이며 막대 길이도 갱신된다. 그래프 라이브러리는 쓰지 않는다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 선택지마다 비율(%)과 같은 길이의 막대가 있다. 0표면 막대가 비어 있다.
- [ ] 내 선택의 막대는 초록색이다.
- [ ] 막대는 보조기기에서 숨겨진다(숫자가 같은 정보를 전달).
- [ ] 다른 사람이 투표하면 새로고침 없이 막대 길이가 바뀐다.
- [ ] Playwright 테스트: 막대 길이가 비율과 일치, 갱신 후 길이 변화.
