# 03: 운영자가 투표 만들기 + 첫 화면 목록

**What to build:** 로그인한 운영자가 `/operator/new`에서 질문 하나와 선택지 2~10개를 입력해 투표를 만든다. 선택지 입력칸은 추가·삭제할 수 있다. 만든 투표는 첫 화면(`/`)의 진행 중인 투표 목록(최신순)과 운영자 목록(`/operator`, 총 투표 수 0)에 바로 나타난다. 여러 투표를 동시에 열어 둘 수 있다.

**Blocked by:** 02 (운영자 로그인과 로그아웃)

**Status:** done

- [x] 질문 + 선택지 2~10개로 투표를 만들면 첫 화면과 운영자 목록에 바로 보인다(최신순).
- [x] 선택지 입력칸을 추가·삭제할 수 있고, 10개를 넘게 추가할 수 없다.
- [x] 선택지 1개 이하, 11개 이상, 빈 선택지, 빈 질문은 거부되고 이유가 보인다. 앞뒤 공백은 제거한 뒤 검사한다.
- [x] 같은 규칙이 서버(`POST /api/polls`)에서도 지켜진다. 화면을 거치지 않은 요청도 거부된다.
- [x] 로그인하지 않은 사람이 `POST /api/polls`를 직접 호출하면 거부된다.
- [x] 투표와 선택지는 함께 저장된다. 일부만 저장되는 일이 없다. 선택지는 입력한 순서를 유지한다.
- [x] 진행 중인 투표가 없으면 첫 화면에 "진행 중인 투표가 없습니다"가 보인다.
- [x] 생성 직후 목록이 이전 값으로 캐시되어 보이지 않는다.
- [x] Playwright 테스트: 정상 생성 후 두 목록 표시, 각 거부 사례(화면과 API 직접 호출), 비로그인 API 거부, 빈 목록 안내.
