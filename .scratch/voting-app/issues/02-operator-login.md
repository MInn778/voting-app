# 02: 운영자 로그인과 로그아웃

**What to build:** 운영자가 `/login`에서 공유 비밀번호를 입력하면 로그인되어 운영자 화면(`/operator`)에 들어갈 수 있다. 로그인은 1일 동안 유지되고, 로그아웃 버튼으로 직접 끝낼 수 있다. 로그인하지 않은 사람이 운영자 화면에 들어오면 로그인 화면으로 보내진다(ADR-0001: 개인 계정 없이 공유 비밀번호 하나).

**Blocked by:** 01 (기반 설정)

**Status:** done

- [x] 올바른 비밀번호(`OPERATOR_PASSWORD`)로 로그인하면 `/operator`로 이동한다.
- [x] 틀린 비밀번호면 로그인되지 않고 오류 안내가 보인다.
- [x] 세션은 `SESSION_SECRET`으로 서명된 httpOnly 쿠키이며 1일 후 만료된다. 서명이 없거나 변조된 쿠키는 로그인으로 인정되지 않는다.
- [x] 로그아웃 버튼을 누르면 세션이 끝나고 첫 화면(투표 목록)으로 이동하며, 이후 `/operator` 접근 시 로그인 화면으로 이동한다.
- [x] 로그인하지 않고 `/operator` 아래 경로에 들어가면 로그인 화면으로 이동한다.
- [x] 운영자 전용 API가 공통으로 쓸 "운영자 세션 확인" 수단이 있다(이후 티켓의 생성·삭제 API가 각자 재검증에 사용).
- [x] Playwright 테스트: 로그인 성공, 로그인 실패, 비로그인 리다이렉트, 로그아웃.
