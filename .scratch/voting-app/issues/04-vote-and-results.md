# 04: 투표자 투표 + 결과 보기

**What to build:** 투표자가 로그인 없이 첫 화면에서 투표를 골라(`/polls/[id]`) 선택지 하나에 투표하면, 바로 결과 화면(`/polls/[id]/results`)으로 이동해 선택지별 득표수, 비율, 총 투표 수를 본다. 투표한 브라우저에는 그 투표 전용 참여 쿠키가 남아, 같은 브라우저에서는 다시 투표할 수 없고 재방문 시 결과로 바로 간다. 투표하지 않은 사람은 결과를 볼 수 없고, 운영자는 모든 결과를 언제든 볼 수 있다(ADR-0001: 쿠키 기반의 약한 중복 방지).

**Blocked by:** 03 (운영자가 투표 만들기 + 첫 화면 목록)

**Status:** done

- [x] 투표 화면에 질문과 모든 선택지가 입력 순서대로 보이고, 정확히 하나만 고를 수 있다. 아무것도 고르지 않으면 제출되지 않는다.
- [x] 제출하면 그 선택지 득표수가 1 늘고 결과 화면으로 이동한다. 득표수 증가는 동시 투표에도 값이 꼬이지 않는다.
- [x] 다른 투표의 선택지 id로 투표하는 요청은 거부된다.
- [x] 결과 화면에 선택지별 득표수, 비율(정수 % 반올림), 총 투표 수가 보인다. 총 0표면 모두 0%다. 목록으로 돌아가는 링크가 있다.
- [x] 같은 브라우저로 투표 화면을 다시 열면 결과 화면으로 간다. 오래된 화면에서 재제출해도 표는 기록되지 않고 결과 화면으로 간다.
- [x] 투표하지 않은 브라우저가 결과 주소에 들어가면 투표 화면으로 간다. 결과 API도 참여 쿠키나 운영자 세션이 없으면 응답하지 않는다.
- [x] 로그인한 운영자는 투표하지 않고도 모든 결과를 볼 수 있다. 운영자 목록에서 결과로 가는 링크가 있다.
- [x] 한 투표자가 여러 투표에 각각 한 번씩 투표할 수 있다.
- [x] 없는 투표 주소로 들어가면 "투표를 찾을 수 없습니다"가 보인다.
- [x] 투표·결과 화면은 항상 최신 DB 값을 보여준다.
- [x] Playwright 테스트: 투표 후 결과 이동과 숫자 확인, 여러 브라우저 컨텍스트로 여러 투표자 흉내, 재방문·재제출 차단, 미참여자 결과 차단, 운영자 결과 열람, 없는 투표 안내.
