# 05: 결과 자동 갱신 (5초 폴링)

**What to build:** 결과 화면을 열어 둔 채로 다른 투표자가 투표하면, 새로고침하지 않아도 5초 안에 득표수, 비율, 총 투표 수가 최신 값으로 바뀐다. WebSocket 같은 서버 푸시는 쓰지 않는다.

**Blocked by:** 04 (투표자 투표 + 결과 보기)

**Status:** done

- [x] 결과 화면이 5초마다 결과 API를 다시 불러 숫자를 갱신한다.
- [x] 화면을 떠나면 폴링이 멈춘다.
- [x] 폴링 요청도 04의 결과 열람 규칙(참여 쿠키 또는 운영자 세션)을 따른다.
- [x] 폴링 중 투표가 삭제되어 결과를 못 받으면 오류 대신 "투표를 찾을 수 없습니다"가 보인다.
- [x] Playwright 테스트: 결과 화면을 연 컨텍스트와 별도 컨텍스트에서 투표 → 새로고침 없이 숫자가 바뀜.
